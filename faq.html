FAQ & Troubleshooting

Answers to common Uranium setup, command, permissions and dashboard questions.

Documentation • Updated 7 November 2026

The bot is offline or slow

Free hosting may pause inactive services, so the first request can be delayed while the service wakes. Check the hosting status and try a simple ping command.

A command says Missing Permissions

Check the bot’s channel permissions, the invoking member’s permissions and the bot role position. The bot cannot override Discord role hierarchy.

Prefix commands do not work

Confirm the server prefix and check whether Message Content Intent is enabled and approved where required. Slash commands can be used as an alternative where registered.

Dashboard does not show my server

Log in with the Discord account that manages the server. The account needs Manage Server or ownership, and the server must be returned by Discord OAuth.

AI features are unavailable

AI is disabled by default pending provider and audience compliance review. Do not try to enable it by changing client-side controls.

How do I report a problem?

Use the in-bot /support report command if it is available in your server, or review the project on GitHub.

Still stuck?

Check the command library, getting started guide and permissions guide.
