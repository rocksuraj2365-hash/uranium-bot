Changelog

A concise record of notable Uranium website, command and policy updates.

Documentation • Updated 20 November 2026

20 November 2026 · Premium payments and status

  • The Premium page now works end to end. Log in with Discord, pick a plan, pay by UPI and send the transaction ID.
  • Your status updates by itself: waiting for payment, waiting for the owner check, approved or rejected.
  • Access starts only after the owner confirms the real payment with one tap. Monthly and yearly plans expire on their own, and No Prefix is included while Premium is active.
  • A transaction ID can only be used once, and each order has its own reference code.

19 November 2026 · Anti-Nuke v2

  • Anti-Nuke now works on its own. Uranium Fortress no longer has to be enabled first.
  • Choose the punishment: timeout, strip dangerous roles, kick or ban. Alerts always reach the mod-log channel, the system channel or the server owner.
  • New interactive control panel with /antinuke panel or !antinuke. The previous status view is /antinuke config or !anconfig.
  • Alert cards include Ban actor, Whitelist and Mark reviewed buttons for the server owner, Extra Owners and members with Manage Server.
  • The public command library now lists 504 commands.

7 November 2026 · Documentation hub

  • Added a central documentation index and setup guides.
  • Added focused pages for permissions, moderation, AutoMod and dashboard usage.
  • Added FAQ, changelog and support navigation.
  • Linked relevant official Discord developer references.

7 November 2026 · Command library

Published a searchable public command catalogue and updated interactive help pagination. Access labels in the catalogue indicate owner-only and Premium restrictions.
