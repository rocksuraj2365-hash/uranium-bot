Getting Started

Invite Uranium and complete a safe first-time setup in your Discord server.

Documentation • Updated 7 November 2026

1. Invite Uranium

Use the official Invite Bot route. Review the OAuth permission screen before authorizing. Do not grant Administrator unless a feature genuinely requires it and you understand the risk.

2. Check bot role position

In Server Settings → Roles, move the Uranium role above the roles it must manage, but keep it below trusted staff roles. Discord prevents bots from managing roles and members at or above their highest role.

3. Configure a moderation log channel

Create a private staff-only channel for moderation logs. Use the matching configuration command from the command library. Confirm that only appropriate staff can read the channel.

4. Test with low-impact commands

Start with help, ping and server information commands. Test moderation actions with a trusted test account and explain the server rules to moderators first.

Optional: create a support server

In a new server, invite Uranium and run /template support or !template support. The builder creates six categories, 27 channels, 12 styled roles, a rules-acknowledgement button and private support tickets. You need Manage Server, and Uranium needs Manage Channels and Manage Roles. The builder preserves existing channels and roles. Review the rules and assign trusted staff to the generated staff roles before opening the server.

5. Tell members what is collected

Link the Privacy Policy in your server information channel. Explain which moderation records your staff keep and how members can raise a concern.
