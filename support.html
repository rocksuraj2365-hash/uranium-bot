Find answers, report a bot issue, or review the project.

Before reporting

  1. Check the FAQ and permissions guide.
  2. Copy the exact command name and error text. Never include tokens, passwords or private credentials.
  3. Describe what you expected and what happened instead.

Report from Discord

Use /support report if available. Reports are routed to the configured support destination. Do not submit private information about other members unless it is necessary to explain a safety issue.

Build a complete support server

Server owners can run /template support or !template support to create six categories, 27 channels and 12 styled roles, plus an interactive rules-acknowledgement panel and private support tickets. The person running it needs Manage Server. Uranium needs Manage Channels and Manage Roles, with its highest role above the roles it creates. The template does not delete existing channels or roles. Review the generated rules, assign trusted staff to the staff roles, and test the ticket and verification buttons before inviting members.
