Verify User

This page explains the verification-related steps a user may meet when using Uranium, and what Uranium does not do.

Last updated: 5 November 2026

Important: Uranium does not provide official Discord identity verification and does not verify your legal identity. In the current code there is no built-in Uranium “verify your account” system, no identity-document check and no separate Uranium verification form. This page must not be presented as Discord’s own verification.

What “verification” can mean here

  • Dashboard login: signing in through Discord OAuth. This proves to the dashboard that you control a Discord account, because Discord itself checks your login. Uranium does not check your password.
  • A server’s Discord verification level: a Discord server setting (none, low, medium, high or very high) that Discord enforces before members can participate. An administrator with the Manage Server permission can change that Discord setting with /server verification-level. Uranium only changes the setting; Discord applies it.
  • Server-specific checks by staff: an individual server may ask members to follow its own rules, use a role panel or open a support ticket. Those steps belong to that server, not to an official Uranium or Discord identity programme.

How to complete dashboard login

  1. Open the dashboard and choose Login with Discord. Uranium sends you to Discord’s own authorisation page.
  2. Check that you are on Discord, check which Discord account you are using, and read the permissions (scopes) Discord shows before approving.
  3. Approve only if you recognise the request. Discord sends you back to Uranium, and Uranium opens your dashboard if the login succeeds.
  4. Log out with Logout when you are finished, especially on a shared device.

Inside a Discord server, follow that server’s instructions for any server-specific gate or role step. If you are unsure which step applies, ask that server’s staff rather than guessing.

Never requested by this page: your Discord password, a Discord user/bot token, OAuth codes to paste in, payment details or identity documents. Do not give those to anyone claiming to run “Uranium verification”.

How results are handled

  • A successful dashboard login creates a dashboard session and sends you to the dashboard. The session stores the Discord user and server list described in the Privacy Policy.
  • A failed login shows a login-failed or invalid-state message and does not open the dashboard.
  • Changing a server’s verification level changes a Discord server setting. It does not create an Uranium “verified user” badge or status.
  • Role buttons and tickets, if a server uses them, do what they say in that server (for example toggle a role or open a private ticket channel). They are not identity checks.

If verification or login fails

  1. Make sure you approved the request while signed into the correct Discord account, then try logging in again from the dashboard. An out-of-date or mismatched login attempt is rejected and must be restarted.
  2. If a server gate will not let you speak, check that server’s rules and Discord’s own requirements for its verification level (for example a verified email on your Discord account is a Discord requirement at some levels). Uranium support cannot override Discord’s checks.
  3. If a button, role or ticket does not work, note the exact error message and the time, and tell server staff. Do not keep retrying a high-impact action.
  4. Never “fix” a failure by sending a password, token, login code or personal document to a person or a bot.

Contacting server staff

For help in a server, contact that server’s administrators or moderators — for example through its support channel, or a ticket if that server has opened a ticket panel. Explain what you tried and quote the error message, but do not include passwords, tokens or codes. Server staff decide server-specific access; they cannot change your Discord account’s official verification status, and neither can Uranium.
