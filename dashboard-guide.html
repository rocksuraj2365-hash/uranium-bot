Dashboard Guide

Connect with Discord OAuth and configure Uranium for servers you can manage.

Documentation • Updated 7 November 2026

Sign in safely

Open the Discord login page and review the requested OAuth scopes. Uranium requests identity and server-list access for dashboard selection. It never needs your Discord password or user token.

Choose a server

The dashboard lists servers returned by Discord where your account is the owner or has the required server-management permission. If a server is missing, check that you are logged into the correct Discord account and that you have Manage Server permission.

Apply settings carefully

Review each setting before saving. Changes are sent to the bot service and checked against your Discord user ID and server permissions. If the bot is asleep on free hosting, the first request may take longer while it wakes.

Session safety

Use your own device, log out on shared devices and never share login links or session cookies. If something looks wrong, log out and review your Discord Authorized Apps.
